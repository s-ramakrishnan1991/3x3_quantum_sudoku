# Quantum Computing Labs with Qiskit

![Python](https://img.shields.io/badge/Python-3.x-blue)
![Qiskit](https://img.shields.io/badge/Qiskit-Quantum-purple)
![License](https://img.shields.io/badge/License-MIT-green)

A collection of quantum computing laboratory exercises developed using **Qiskit** and **Jupyter Notebook** as part of coursework at the **University of Arkansas at Little Rock**.

The labs introduce the fundamentals of quantum computing and progress to implementing important quantum algorithms and protocols.

---

## Repository Contents

### Lab 0 — Introduction and Programming Quantum Computers

This notebook introduces the basic concepts of quantum computing and quantum programming.

Topics include:

- Classical vs Quantum Computing
- Qubits
- Bloch Sphere
- Quantum Gates
- Quantum Circuits
- Measurement
- Programming with Qiskit

---

### Lab 1 — Quantum Teleportation

Implementation of the Quantum Teleportation protocol using Qiskit.

Topics include:

- Quantum Entanglement
- Bell States
- Alice and Bob Protocol
- Classical Communication
- Quantum Circuit Implementation
- Teleportation Verification

---

### Lab 2 — Solving a 3×3 Sudoku using Grover's Algorithm

Implementation of **Grover's Search Algorithm** to solve a **3×3 Sudoku puzzle**.

Topics include:

- Oracle Construction
- Phase Oracle
- Diffusion Operator
- Amplitude Amplification
- Quantum Search
- Sudoku Constraint Encoding
- Measurement and Solution Verification

## Installation

Clone the repository

```bash
git clone https://github.com/<your-username>/quantum-computing-labs.git
cd quantum-computing-labs
```

Install dependencies

```bash
pip install qiskit numpy matplotlib jupyter
```

Launch Jupyter Notebook

```bash
jupyter notebook
```

Open the notebooks in order:

1. Lab0.ipynb
2. Lab1.ipynb
3. Lab2.ipynb
